# 変更ログ：マップ3段階ズーム倍率連動・左上メニュー刷新・旅行まとめ（思い出）画面の実装

## 1. 変更日時・作業ブランチ

- **変更日時**：2026-11-07 20:12
- **作業ブランチ**：`ui/top-screen`

## 2. 背景・目的（Background）

- 起動直後の画面を日本全体（または端末のロケール国全体）の「1倍表示」とし、倍率に応じて「県の形に沿った写真表示」→「市の形に沿った写真表示」→「ピン＋Googleマップ詳細表示」へ段階的に切り替えることで、写真の見やすさとシンプルな地図デザインを両立するため。
- 簡易地図ボタン・都道府県フォトボタン・方位磁石を削除し、全体表示ボタンを「1倍画面に戻すホームボタン」に変更するため。
- 上部メニューを1倍時のみ表示とし、白いカード背景を廃止して画面左上に文字とアイコンをスタイリッシュに集約するため。
- 「旅行スタート（旅行名入力）〜旅行終了（旅行まとめ自動作成）」と、ホームタブの「思い出ボタン（開始ボタンと招待ボタンの間）」およびスケッチUI準拠の「思い出一覧・詳細画面」を実装するため。

## 4. 変更理由・設計判断（Why）

- **Web Mercator投影による同期座標算出**：Google Mapのカメラ移動（`onCameraMove`）に対して非同期通信ラグなしで県・市シルエットおよびピン直上のレビュー吹き出しを追従させるため、Web Mercator投影計算を用いて画面座標を同期算出する設計を採用した。
- **Mapスタイルの段階的切替**：低・中倍率では写真シルエットの視認性を損なわないよう道路・POI・文字ラベルを非表示にして県境（`administrative.province`）のみを描画し、ピンが表示される高倍率でのみ詳細スタイルへ切り替える構成とした。
